# Backend - TTPS-E (Sistema de Seguimiento de Estudios de Exoma Clínico)

## Comandos

Ejecutar desde `backend/`:

- Instalar dependencias: `poetry install`
- Ejecutar servidor Flask: `poetry run flask --app main run`
- Ejecutar tests: `poetry run pytest`
- Ejecutar linter: `poetry run ruff check .`
